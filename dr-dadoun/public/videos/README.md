# Vidéos du site

| Fichier | Emplacement |
| --- | --- |
| `hero.mp4` | Arrière-plan de la première page (en boucle, sans son) |

Tant que le fichier est absent, la photo `images/hero.jpg` (ou le dégradé cyan) s'affiche.
Les visiteurs qui ont activé « réduire les animations » voient aussi l'image fixe.

Recommandations :
- format MP4 (H.264), 1920 × 1080, 10 à 20 secondes, sans piste audio ;
- poids idéal : moins de 8 Mo (limite d'envoi sur GitHub : 25 Mo) ;
- plan calme, sans texte incrusté, avec une zone plus sombre à gauche pour la lisibilité du titre.

Droits : utilisez uniquement une vidéo dont vous détenez les droits (tournage du cabinet,
banque d'images sous licence). Une vidéo trouvée sur Pinterest appartient à son auteur.
